# AP-K8S-003 — Container image with :latest tag or no tag

**Category:** security | **Severity:** error
**Frameworks:** [plain]

## Summary
The `latest` tag (or no tag) makes deployments non-deterministic — the same manifest can pull different images across nodes or over time. Pin images to an immutable digest or an explicit version tag, and use a digest for production workloads.

## Do Not Write
```yaml
image: my-app:latest
```

## Instead Write
```yaml
image: my-app:1.4.2@sha256:abc123def456...
```

## Detection
- kube-linter: `latest-tag`
