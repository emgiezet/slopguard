# AP-K8S-002 — Missing CPU and memory resource requests and limits

**Category:** performance | **Severity:** error
**Frameworks:** [plain]

## Summary
Containers without resource requests are scheduled on any node regardless of capacity; containers without limits can consume all node resources and starve neighbouring pods. Define requests and limits for every container.

## Do Not Write
```yaml
containers:
  - name: app
    image: my-app:latest
    # no resources block
```

## Instead Write
```yaml
resources:
  requests: { cpu: "250m", memory: "256Mi" }
  limits:   { cpu: "500m", memory: "512Mi" }
```

## Detection
- kube-linter: `unset-cpu-requirements`
- kube-linter: `unset-memory-requirements`
