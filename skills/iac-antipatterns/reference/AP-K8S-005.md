# AP-K8S-005 — Secrets passed as literal environment variables or in ConfigMap

**Category:** security | **Severity:** blocker
**Frameworks:** [plain]

## Summary
Embedding secret values directly in pod specs or ConfigMaps stores them in etcd in plaintext and exposes them to anyone who can read the pod spec. Reference Kubernetes Secrets (with etcd encryption at rest enabled) or an external secrets operator.

## Do Not Write
```yaml
env:
  - name: DB_PASSWORD
    value: "hunter2"
```

## Instead Write
```yaml
env:
  - name: DB_PASSWORD
    valueFrom:
      secretKeyRef: { name: db-credentials, key: password }
```

## Detection
- kube-linter: `env-var-secret`
- betterleaks: `generic-api-key`
