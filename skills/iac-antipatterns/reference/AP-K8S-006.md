# AP-K8S-006 — Writable root filesystem, hostNetwork, or dangerous hostPath mounts

**Category:** security | **Severity:** error
**Frameworks:** [plain]

## Summary
A writable root filesystem lets a compromised container persist changes. `hostNetwork: true` shares the node's network namespace. Host path mounts expose sensitive node directories. Use `readOnlyRootFilesystem: true`, avoid `hostNetwork`, and whitelist specific safe paths for volume mounts.

## Do Not Write
```yaml
securityContext:
  readOnlyRootFilesystem: false
volumes:
  - name: host-dir
    hostPath: { path: /etc }
```

## Instead Write
```yaml
securityContext:
  readOnlyRootFilesystem: true
# emptyDir for tmpfs writes; specific safe hostPaths only
```

## Detection
- kube-linter: `no-read-only-root-fs`
- kube-linter: `host-network`
- kube-linter: `sensitive-host-mounts`
