# AP-K8S-001 — Privileged container, privilege escalation, or running as root

**Category:** security | **Severity:** blocker
**Frameworks:** [plain]

## Summary
A privileged container has the same access to the host as a root process and can escape the container boundary. Prevent privilege escalation and enforce a non-root UID with `securityContext` at the pod and container level.

## Do Not Write
```yaml
securityContext:
  privileged: true
```

## Instead Write
```yaml
securityContext:
  runAsNonRoot: true; runAsUser: 1000
  allowPrivilegeEscalation: false
  capabilities: { drop: ["ALL"] }
```

## Detection
- kube-linter: `privileged-container`
- kube-linter: `privilege-escalation-container`
- kube-linter: `run-as-non-root`
